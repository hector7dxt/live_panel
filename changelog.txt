# Histórico de Versiones (Changelog)

## [2.0.0] - Autenticación y Colaboración (Actual)
### Añadido
- **Sistema de Autenticación:** Integración de Firebase Auth para acceso privado mediante usuario y contraseña, protegiendo los datos y creando tableros individuales por usuario.
- **Dominios Autorizados:** Seguridad mejorada al restringir el inicio de sesión exclusivamente a los dominios configurados, como GitHub Pages.
- **Espacios de Trabajo (Pestañas):** Creación de un sistema de doble vista en el panel principal:
  - **👤 Mi Tablero:** Espacio completamente privado exclusivo para el usuario autenticado.
  - **🌍 Espacio Compartido:** Tablero público colaborativo visible y editable por todos los usuarios registrados en el sistema.
- **Reglas de Seguridad (Firestore):** Implementación de reglas estrictas para aislar los datos privados (`visibility: private`) de los datos públicos (`visibility: public`), garantizando la privacidad de las tarjetas personales.
- **Ingreso Rápido:** Soporte para iniciar sesión presionando la tecla `Enter` directamente desde el campo de contraseña.

### Modificado
- **Arquitectura Modular (Refactor):** Separación total del código en un modelo profesional de carpetas y archivos. El proyecto pasó de un único archivo monolítico a una estructura mantenible (`index.html`, `/css/style.css`, `/js/app.js`).
- **Prevención de Errores Silenciosos:** Se implementó una capa de validación en los elementos del DOM (`if (elemento)`) dentro del motor JavaScript para evitar bloqueos por carga asíncrona o elementos no renderizados.

## [1.4.1] - Hotfix
### Corregido
- **Clausura obsoleta (Stale Closure):** Se solucionó un bug lógico donde los botones de las tarjetas (Bloquear, Fijar, Color, Código) dejaban de funcionar tras el primer clic al memorizar el estado inicial de la base de datos. Ahora los eventos leen el estado del DOM en tiempo real.

## [1.4.0] - Versión "Ultra"
### Añadido
- **Modo Código (`</>`):** Funcionalidad para cambiar la tipografía a formato monoespaciado.
- **Etiquetas de Color (🎨):** Sistema de colores (Rojo, Azul, Verde, Amarillo) adaptados al modo claro y oscuro.
- **Bloqueo de Seguridad (🔒):** Estado de solo lectura que deshabilita edición, borrado y drag & drop.
- **Tarjetas Fijadas (📌):** Opción para anclar tarjetas al inicio del panel.
- **Modal QR (📱):** Botón global para acceso rápido desde dispositivos móviles.
- **Limpieza Automática (⏳):** Interruptor para eliminación automática tras 24h sin modificaciones.

### Modificado
- **Placeholders Dinámicos:** Textos fantasma reales (`data-placeholder`) en las nuevas tarjetas.

## [1.3.0] - Mejoras de UX/UI y "Pro"
### Añadido
- **Modo Oscuro (Dark Mode):** Paleta invertida con persistencia en `localStorage`.
- **Botón Copiar (📋):** Extracción de texto al portapapeles con confirmación visual.
- **Auto-Link (Linkify):** Detección automática de URLs.
- **Skeleton Loader:** Animación de carga para mejorar la UX durante la conexión a Firebase.
- **Ghosting Drag & Drop:** Indicador visual predictivo para reordenamiento de tarjetas.

### Modificado
- **Descarga Directa:** Descargas automáticas en la misma pestaña mediante el atributo `download`.
- **Feedback de Guardado:** Estados "⏳ Guardando..." y "✅ Guardado" en tiempo real.

## [1.2.0] - Migración Serverless
### Añadido
- **API Externa (tmpfiles.org):** Integración de subidas `XMLHttpRequest` para archivos.
- **Barra de Progreso:** UI de progreso en tiempo real para cargas.
- **Cancelación Segura:** Capacidad para abortar subidas en curso.

### Eliminado
- **Firebase Storage:** Dependencia eliminada para un despliegue puramente estático en GitHub Pages.

## [1.1.0] - Intento de Archivos (Legacy)
### Añadido
- Soporte inicial para archivos (50MB) usando Firebase Storage. (Depreciado).

## [1.0.0] - Lanzamiento Inicial ("Panel Vivo" Base)
### Añadido
- Sincronización bidireccional en tiempo real (Firebase Firestore).
- Tarjetas con Título, Contenido principal y Notas extra.
- Drag & Drop básico.
- Sistema `debounce` para optimizar escrituras.
- Borrado masivo.
